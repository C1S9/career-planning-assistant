# Changelog

## 0.4.0 — 2026-10-23

- Added an application permission gateway before the two implemented network transports: primary-source search and model completion.
- Added fixed destination and data-category checks, request expiry, revocation, shared per-request call budgets, and restricted research/writing capability scopes.
- Added network-pause controls and bounded, memory-only audit metadata without raw chat, source content, queries, keys, or provider errors.
- Left unimplemented external actions and permission administration denied; no email, payment, arbitrary upload, or independent model-agent team was introduced.
- Bundled the gateway and added an offline executable probe for budget, delegated revocation, and paused-network enforcement. Added an English permission and learning guide.

## 0.3.0 — 2026-10-23

- Added live primary-source retrieval before advice, private topic queries, optional region selection, actual source panels, and honest failure handling.
- Added current-source ID/link validation and source-grounded checked plans.
- Added three English skills loaded at runtime for evidence, selected mentor workflows, and planning.
- Included evidence modules and skill files in the portable Windows package and offline bundled checks.


## 0.2.0 — 2026-10-22

Added five life-consultation mentor presets, an uncluttered sidebar layout, native light/dark themes, session-only API entry, and a Windows portable application. Added version metadata, reproducible packaging, dependency notices, checksums, and GitHub Actions for tests and tagged builds. Existing checked-plan rules and bounded correction remain in place.

The Windows launcher opens the local app in the default browser and owns its loopback-only server process. Users do not install Python or deploy a server. They still supply authorized DeepSeek API access.

## Initial demo

DeepSeek career conversation, retained session context, explicit retries, checked task-plan generation, public source repository, and English technical learning documentation. The earlier demo had no packaged Windows release.
