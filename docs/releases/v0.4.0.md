# Life Direction Agent v0.4.0

Search and model operations now pass through a program-enforced permission gateway before their network transport starts. Existing mentor conversations, primary-source retrieval, runtime coaching skills, citation checks, and checked plans remain available.

- Each explicit send, plan, or retry receives a short-lived, request-scoped grant with fixed DeepSeek destinations and declared data categories. Grants are revoked on completion or failure.
- Research scopes can search; writing and planning scopes can complete model requests. Delegation cannot widen a role, add a destination, or increase the shared parent call budget. These scopes are Python workflow components, not newly launched reasoning agents.
- Chat allows at most two search starts and one completion. Plans allow at most two search starts and two completions, including correction. A transport failure still consumes its reservation; call counts do not impose a monetary spending limit.
- The Permissions controls can pause new network starts and lower per-request search or plan-completion limits. Recent activity shows sanitized request counts and audit events. An already-running transport may finish. Audit data stays in bounded conversation memory and contains no raw payloads or API credentials.
- The Windows package includes the gateway. Its offline self-test checks a local allowed callback, an exhausted budget, inherited revocation, and paused-network denial without calling the provider.

Download `LifeDirectionAgent-v0.4.0-windows-x64.zip`, extract the entire folder, and open `LifeDirectionAgent.exe`. Keep `_internal` beside the executable. Internet access, your own authorized DeepSeek key, and available balance are required for generated replies and search. The application includes no owner's credentials or prepaid access.

Eighty-eight offline application tests passed. A fictional-context live chat and three-day checked plan each used one search and one model completion, with both grants revoked afterward. The offline permission probe passed using only local callbacks. See `BUILD_REPORT.json` for completed executable checks and `SHA256SUMS.txt` for the exact archive checksum; the CI run reports the repository's test results.

The gateway protects the registered application call paths. It is not an operating-system sandbox, does not make Python plugins untrusted-safe, and does not automatically prove advice correctness. External actions such as email, payment, arbitrary uploads, and permission administration are not registered. Audits are not durable or tamper-proof. There is no automatic updater; download this version to receive the changes. The executable remains unsigned and application license selection remains pending.
