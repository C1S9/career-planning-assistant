# v0.5.0 — Graduate career workbench

This version focuses the app on mainland China students and recent graduates preparing for internships and campus recruitment.

## Changes

- Added a structured student profile used as context for requested career guidance.
- Added a role-and-city market brief backed by primary-source research, with explicit gaps when current evidence is unavailable.
- Added local job-description and experience comparison through supported skill keywords. Results show mentions and missing mentions; they are not ATS scores or hiring predictions.
- Added a session-only application tracker with validated CSV import and export.
- Added Markdown download of checked action plans.
- Retained optional mentor styles, DeepSeek access, source panels, permission controls, retries, and checked-plan validation.
- Added the new modules to the Windows bundle and source-hash manifest. The launcher remains `LifeDirectionAgent.exe`.

## Availability and verification

See [release status](../RELEASE_STATUS.md) for validation results, the [Releases page](https://github.com/C1S9/career-planning-assistant/releases) for published packages, and the accompanying BUILD_REPORT.json for the portable package checks.

The portable package requires the user's own DeepSeek API access for online features. It includes no prepaid API balance. Local comparison and tracker tools do not require a key.

## Validation recorded on October 24, 2026

- 129 automated tests passed, including student context, real request boundaries with simulated HTTP, CSV edge cases, and Streamlit interaction tests.
- Live DeepSeek checks using fictional student details returned a sourced market brief, a career reply, and a checked three-day plan. Each used two searches and one model completion; all permissions closed afterward.
- The live sources were individual NCSS postings with unknown publication years. The brief identified those limits; this check does not establish live vacancy availability or representative market conditions.
- Playwright browser checks covered desktop and narrow layouts and the local bilingual skill comparison. The tracker uses its explicit, schema-preserving CSV download instead of generic table exports.
- The Windows x64 package passed its isolated self-test with external Python removed from PATH, including the launcher, server, app page, source filters, permissions, profile, skill comparison, CSV round trip, and advice export.
- All 20 runtime source hashes match the build manifest. The actual ZIP was scanned for the locally configured key and private filenames; no matches were found.

The package remains unsigned, and its offline self-test makes no paid API calls. Test fixtures and the live smoke checks use fictional data. API keys, personal profiles, tracker records, and generated build folders are excluded from the public source update.

## Limits

Official portal links are discovery aids. A vacancy, salary, or deadline is not current merely because its domain is trusted. The app does not apply to jobs, contact recruiters, host a persistent account, or guarantee employment. Profile and tracker data are held in session memory; export records before closing.
