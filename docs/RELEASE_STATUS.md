# Version 0.3.0 release status

Version 0.3.0 adds live primary-source retrieval, source-reference validation, and three runtime coaching skills. See [release notes](releases/v0.3.0.md), [validation record](VALIDATION_v0.3.0.md), and [evidence and skills](EVIDENCE_AND_SKILLS.md).

The intended release location is [v0.3.0](https://github.com/C1S9/career-planning-assistant/releases/tag/v0.3.0). Verify the published assets and their BUILD_REPORT.json before treating the executable as released. The source preparation record itself is not evidence of publication.

The previously verified [v0.2.0 release](https://github.com/C1S9/career-planning-assistant/releases/tag/v0.2.0) remains available. New capabilities require the new package; no background updater is installed.

Model replies and search require internet access and the user's own authorized DeepSeek key. Source identifiers and schedules are checked; factual accuracy and personal suitability are not certified. The Windows executable remains unsigned.
