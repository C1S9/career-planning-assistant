TECHNICAL REFERENCE · VERSION 0.2.0

One conversation.
A mentor for your next step.

Five instruction presets share a DeepSeek backend. An explicit action-plan operation validates fields and dates before displaying a checked result.

This is a static reference route, not evidence of a completed hands-on code tour. It works offline without scripts or external assets.

1. Choose and send

app.py → new_conversation, queue_message

The sidebar selects a mentor id. Switching clears old context and request permission. A send stores one user turn and grants permission for a single request.

Where the preset lives

mentors.py → MENTORS, get_mentor provides each purpose, welcome, and instruction. No model is trained by switching a preset.

2. Generate

agent.py → reply, generate_plan

The selected mentor reaches prompts.system_prompt or plan_system_prompt. The provider receives the current transcript and explicit system instructions. A malformed plan permits at most one correction.

3. Check and display

models.py → parse_plan, format_plan

Required fields and date rules are checked against the saved selection. app.py adds its own checked marker only after validation succeeds. This does not establish personal suitability.

The Windows route

LifeDirectionAgent.exe → desktop.py → st.App.run → app.py

A small Tk window owns a child server listening only on 127.0.0.1 and opens the default browser. Quit stops that child. Python, native libraries, and frontend assets travel with the ZIP; the user's API key does not.

packaging/windows.spec uses an explicit allowlist. scripts/build_windows.py verifies the frozen app, then adds notices, manifests, and checksums.

To change this, start here

  • Mentor purpose and welcome: mentors.py.
  • Shared consultation rules: prompts.py.
  • Colors or light/dark palettes: .streamlit/config.toml.
  • Sidebar controls and session behavior: app.py.
  • Plan fields and schedule rules: models.py.
  • Desktop startup and shutdown: desktop.py.
  • Release number: version.py, VERSION, and Windows version resources.

A practice to reuse

Keep generated claims separate from program-owned state. The app saves the selected mentor and period before requesting output. Tests check that mentor switches do not leak prior context and that the model cannot substitute its own planning period.

Use tests/test_mentors.py and tests/test_plans.py as concrete references. A live response, a simulated failure check, and a frozen-package smoke test establish different facts.

Run and verify

.\.venv\Scripts\python.exe -m streamlit run app.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts/build_windows.py

For the portable build, extract the whole ZIP and open the exe. See docs/WINDOWS_QUICKSTART.md for session-only connection setup.
