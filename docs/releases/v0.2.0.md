# Life Direction Agent v0.2.0

## Windows download

Download `LifeDirectionAgent-v0.2.0-windows-x64.zip`, extract the whole folder, and double-click `LifeDirectionAgent.exe`. Keep the `_internal` folder beside it. Python and a separate deployment are not required.

The app opens locally in your default browser. Keep the small launcher window open and use **Quit** to stop the server. Generated replies require internet access and your own authorized DeepSeek API key; no owner's key or prepaid API access is included.

## Changes

- Five mentor presets: career and work, life direction, learning and skills, habits and focus, communication and relationships.
- Mentor-specific welcome messages, conversation instructions, and checked-plan requests.
- Fresh context on mentor changes, so one mentor never inherits another mentor's conversation accidentally.
- A simpler chat canvas with mentor, connection, and planning controls in the sidebar.
- Native light/dark palettes with readable neutral backgrounds and restrained green accents.
- Password-field API entry, session-only credential use, and an explicit forget action.
- Version information in the interface and Windows executable.
- A portable Windows launcher, isolated package smoke check, checksums, and dependency notices.
- Automated application checks and tagged Windows builds in GitHub Actions.

## Verification

Provider-independent tests cover conversation context, bounded requests, errors and retry, task rules, mentor selection and isolation, and session key entry. The packaged smoke test checks the native launcher, plan parsing, local server, frontend asset, and UI script execution with no paid API request. See `BUILD_REPORT.json` for the built artifact's actual result and `SHA256SUMS.txt` for its archive checksum.

The interface and model configuration changed in this version. Simulated responses and startup checks do not independently certify live provider availability or the quality of personal advice. Existing learner-reported live evidence belongs to the earlier conversational and checked-plan demo.

## Notes

Windows x64 only. The executable is not digitally signed. This release provides general coaching, not professional diagnosis or guaranteed outcomes. Chat history and pasted credentials are session-only. No hosted app, background updater, or Devpost submission is included.
