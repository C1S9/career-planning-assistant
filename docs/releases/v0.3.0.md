# Life Direction Agent v0.3.0

Advice now starts with live primary-source retrieval through DeepSeek's Search API. Answers show actual source links, excerpts, and retrieval dates, and distinguish source-supported facts from tentative interpretation and personal choices.

- Search uses the existing privately supplied DeepSeek key and a general topic rather than raw conversation text. Optional source-region selection includes China and English-language regions.
- Named primary publishers, strict HTTPS URLs, page-content availability, topical overlap, score bounds, and dates filter results. Failed retrieval returns a clarification notice; a checked plan is not generated without usable sources.
- Source markers and generated links are checked against the current retrieval. Checked plans retain field/schedule validation and at most one correction using the same evidence.
- Three English runtime skills cover evidence-informed coaching, mentor-specific decision workflows, and realistic action planning. The portable package includes the skills.

Download the Windows x64 ZIP, extract the entire folder, and open `LifeDirectionAgent.exe`. No separate Python installation or server deployment is needed. Internet access, your own authorized DeepSeek key, and available API balance remain necessary. Search may add provider charges. The app does not include the owner's key, a hosted API subscription, or an automatic updater.

Verification includes offline application tests, live fictional-context chat and a three-day checked plan, a China-source retrieval check, required-skill validation, and the packaged offline self-test. Build artifacts include exact smoke-test and checksum reports.

Source identity checks do not prove every claim, publication date, or individual suitability. The privacy-preserving topic vocabulary is intentionally limited; sources can be incomplete or jurisdiction-specific. No application license was selected in this update. The executable remains unsigned.
